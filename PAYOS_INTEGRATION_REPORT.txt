### 5. API ROUTES ✅
File: server/routes/payment.js

A. POST /api/payment/create
   - Input: { planId, planName, amount, billingCycle }
   - Middleware: requireAuth (x-user-id header)
   - Logic:
     * Tạo orderCode unique (timestamp + random, 13 digits)
     * Lưu đơn hàng vào DB với status "pending"
     * Gọi payos.createPaymentLink() với:
       - orderCode, amount, description
       - items array
       - returnUrl (từ env hoặc fallback localhost)
       - cancelUrl (từ env hoặc fallback localhost)
     * Cập nhật checkout_url vào DB
     * Return: { orderCode, checkoutUrl, qrCode }

B. POST /api/payment/webhook
   - Input: PayOS webhook data (body)
   - Logic:
     * Verify signature bằng payos.verifyPaymentWebhookData()
     * Chỉ xử lý khi code === "00" (thanh toán thành công)
     * Idempotency: Skip nếu order đã "paid"
     * Kiểm tra amount khớp
     * Transaction (withTransaction):
       1. Update order status = "paid", paid_at, payos_transaction_id
       2. Hủy subscription cũ cùng loại (interview hoặc cv)
       3. Tạo subscription mới trong user_subscriptions
       4. Update users.sub_plan_interview/cv và sub_expires_interview/cv
       5. Ghi transaction vào bảng transactions
     * LUÔN trả về HTTP 200 (ngay cả khi lỗi để PayOS không retry)

C. GET /api/payment/check/:orderCode
   - Input: orderCode (params)
   - Middleware: requireAuth
   - Logic: Lấy thông tin order từ DB
   - Return: { order }
